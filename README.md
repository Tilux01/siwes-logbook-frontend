# SIWES Logbook Frontend

React frontend for a student industrial work experience logbook system.

## About

The frontend for the SIWES logbook platform, where students record their internship activities and supervisors review them.

## Features

- Internship activity logging
- Supervisor review views
- Role based dashboards

## Tech Stack

- React
- JavaScript
- CSS

## Getting Started

Clone the repository and open the project in your browser or run it with your preferred local server.
